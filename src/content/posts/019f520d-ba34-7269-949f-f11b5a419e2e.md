<p>必应每天都会更新一张高清首页壁纸。这个自建 API 会自动获取当日图片，并提供 PC、手机、自适应、随机图和 JSON 信息接口，可用于网站背景、博客封面、桌面壁纸或自动化脚本。</p>
<blockquote>
<p>在线地址：<a href="https://bing-img.wuw.li/">https://bing-img.wuw.li/</a><br>以下示例均可直接复制；动态接口会随日期或参数返回不同内容。</p>
</blockquote>
<h2>今日壁纸预览</h2>
<figure data-content-type="image"><img src="https://wuw.li/r2-assets/tu/2026-07-19T07-swgmx.webp" alt="必应今日壁纸示例"></figure>

<p>上图已转存到本站对象存储，保证文章封面稳定；需要始终显示当天新图时，请使用下方动态接口。</p>
<h2>推荐接口</h2>
<h3>1. 自动适配设备（推荐）</h3>
<p><code>https://bing-img.wuw.li/auto_302.php</code></p>
<p>根据访问设备返回 PC 横屏或手机竖屏壁纸，并使用 302 跳转，服务器流量占用更小。适合作为网页背景或 Markdown 图片地址。</p>
<h3>2. 直接输出图片流</h3>
<p><code>https://bing-img.wuw.li/auto.php</code></p>
<p>由 PHP 直接输出图片内容。需要一个看起来固定、不暴露上游链接的地址时可用。</p>
<h3>3. 随机壁纸</h3>
<p><code>https://bing-img.wuw.li/random.php</code></p>
<p>从历史收藏中随机返回图片，每次刷新都可能不同，适合登录页和随机背景。</p>
<h3>4. 固定尺寸</h3>
<ul>
<li>手机竖屏：<code>https://bing-img.wuw.li/m_302.php</code></li>
<li>1920×1080：<code>https://bing-img.wuw.li/1920x1080_302.php</code></li>
<li>1366×768：<code>https://bing-img.wuw.li/1366x768_302.php</code></li>
</ul>
<h3>5. 获取图片信息（JSON）</h3>
<p><code>https://bing-img.wuw.li/func.php?info=1</code></p>
<p>会返回日期、标题、版权描述、PC/手机图片地址和推荐 API 链接，适合脚本或前端程序读取。</p>
<h2>通用参数</h2>
<table>
<thead>
<tr>
<th>参数</th>
<th>说明</th>
<th>示例</th>
</tr>
</thead>
<tbody><tr>
<td><code>idx</code></td>
<td>日期偏移，<code>0</code> 为今天，<code>1</code> 为昨天，最多可查询近 7 天</td>
<td><code>?idx=1</code></td>
</tr>
<tr>
<td><code>w</code></td>
<td>自定义宽度</td>
<td><code>?w=1920</code></td>
</tr>
<tr>
<td><code>h</code></td>
<td>自定义高度</td>
<td><code>?h=1080</code></td>
</tr>
<tr>
<td><code>mkt</code></td>
<td>必应地区，如 <code>zh-CN</code>、<code>en-US</code></td>
<td><code>?mkt=en-US</code></td>
</tr>
</tbody></table>
<p>参数通常可以组合。例如：</p>
<p><code>https://bing-img.wuw.li/auto_302.php?idx=1&amp;mkt=en-US</code></p>
<p>表示获取 en-US 地区的昨日壁纸。</p>

<h2>使用建议</h2>
<ol>
<li>想节省自建服务器带宽，优先使用带 <code>_302</code> 的接口；</li>
<li>文章封面需要长期不变时，请下载并转存图片，不要引用“今日壁纸”动态地址；</li>
<li>页面背景可用动态接口，这样每天会自动更新；</li>
<li>调用 JSON 接口时应检查 <code>code</code> 是否为 <code>200</code>，并为网络失败准备默认图片；</li>
<li>壁纸版权归原作者及相关权利人所有，公开或商业使用前请阅读返回数据中的版权说明。</li>
</ol>
